> **살아있는 문서** — 갱신은 이 파일을 직접 수정한다(날짜 스냅샷 신규 생성 금지). 주요 변경 근거는 docs/CONTEXT.md 결정 기록(D번호)으로 남긴다. 최종 갱신: 2026-07-16.

## 검증 가설

MVP는 두 가설을 동시에 검증한다.

- **H1 (P1)**: 3D 배치 미리보기 + 실시간 견적이 "사기 전 망설임"을 해소해 구매 결정을 앞당긴다.
- **H2 (P2)**: 클램프·VESA·하중 호환성 판정이 구매 실패(반품)를 막는다. 경쟁사 미제공 고유 기능.

## P1. 김준서 — 첫 데스크테리어 준비생 (주 페르소나)

- **집단**: 관심 있으나 미실행 (설문 17.3%). D2 핵심 타겟 정의와 일치 — "제한된 예산 안에서, 직접 사보지 않아도, 데스크를 예쁘게 꾸밀 수 있을지 알고 싶은 소비자."
- **한 줄 맥락**: 하루 8시간 이상 책상 앞(설문 53.3%가 이 구간). 유튜브 데스크셋업 영상 저장만 수십 개. 장바구니에 담았다 비우기 반복.

### MVP 기능 매핑

- 책상 선택(라이브러리 드래그 앤 드롭, 규격은 DB 자동 적용)·예산 입력 → **3D 배치 미리보기** (배치 미리보기 긍정 94.3%, 전 기능 중 최고)
- **실시간 견적** (예산 추천 긍정 80.7%)
- **템플릿 복사 → 리믹스** ("잘 꾸며진 템플릿 제공" 자유응답 다수)
- **질문 기반 세팅 추천** (D9 — 예산·니즈 형식화 질문)

### 성공 지표

- 첫 배치 저장 완료율
- 견적 확인율 (배치 세션 중 견적 노출 대비)
- 템플릿 복사 → 수정 전환율

## P2. 박현우 — 낭패 경험자 업그레이드족 (보조 페르소나)

- **집단**: 데스크테리어 경험자 (설문 33.3%).
- **한 줄 맥락**: 셋업 1회 완성. 모니터암 샀다가 클램프가 상판에 안 물려 반품한 적 있음. 지금은 장비 추가할 때마다 규격표 캡처해서 수동 비교.

### MVP 기능 매핑

- **호환성 판정 3종** (D8): 암↔책상(클램프 물림 범위 vs 클램프 물림 두께) / 모니터↔암(VESA·하중) / 소품↔책상(면적·충돌). 적합/조건부/불가 3단계.
- **간격·충돌 확인** (가상 배치 목적 1위 67.6% "간격이나 호환")
- 선정리는 "계획 보조" 수준 — 구현 수준 미결(CONTEXT.md 미결 항목), MVP 포함 여부 요구사항 단계에서 결정.

### 성공 지표

- 호환성 판정 실행율 (배치 세션 대비)
- "불가" 판정 후 대안 제품 클릭율

## 미확인 가정 (배포 후 검증)

- P2-PN3 선정리 페인의 성격: "귀찮음"인지 "막막함"인지 미확인 (D12). 자유응답은 방법·계획 요청형 — 막막함 신호. 배포 후 사용자 인터뷰로 확인.
- P1의 지불 의사: AI 상상도 토큰제(D10) 수용 여부 미검증.

## 타겟이 아닌 사람 (D2)

창문·자연광·바닥 재질까지 종합 고려하는 사용자 — 이미 인테리어 감각이 높거나 업으로 삼는 층. 이들의 요구(방 전체 설계 등)는 요구사항에 반영하지 않는다.
