# DERO Brand Film — Story Structure

Slogan: "마음대로 원하는대로" (As you wish, the way you want). Estimated runtime 75–90s.
Arc: anticipation → DIY assembly failure → frustration → discovering DERO →
simulator verification → (magical) real-world reflection → completion → joy.

## Scene structure (12 scenes)

| Scene | Cuts | Content | Emotional beat |
|---|---|---|---|
| S1 Delivery | 01, 02 | House exterior, truck delivers one package. Protagonist appears, goes inside | Anticipation begins |
| S2 Box mountain | 03, 04, 05 | Desk-setup package pile in the room. Expectant close-up, hand rubbing | Anticipation builds |
| S3 Unboxing | 06-1, 06-2, 06-3 | Top-down: box down → tape tear → hands in | Excitement |
| S4 Failure point 1: monitor arm | 07-1 ~ 07-4, 08 | Parts spread → clamp → VESA → mount fails, monitor slips | First crack |
| S5 Failure point 2: lighting | 09, 10 | New lamp's color temperature clashes with the room | Disappointment |
| S6 Total disharmony | 11, 12, 13 | Finished but nothing matches. Frustration deepens, OTL gag cut | Rock bottom |
| S7 Discovering DERO | 14-1, 14-2, 15, 16, 17, 18 | Laptop lights up → approach → DERO logo → simulator UI | Turning point, hope |
| S8 Simulator work | 19-1 ~ 25-2 | UI operation ↔ magical real-world reflection (arm mounts, lamp swap) intercut | Immersion, joy |
| S9 Time passing | 26-1~3, 27 | House exterior timelapse (day→sunset→night), fade to black | Bridge |
| S10 Morning reveal | 28-1 ~ 28-4, 29 | Sleeping → wake → startled → turn → tilt-up desk reveal | Surprise |
| S11 Joy montage | 30, 31, 32, 33 | Checking arm, lamp, full view; starry-eyed close-up | Delight |
| S12 Ending | 34, logo | Back view survey + zoom out → DERO logo end card | Brand convergence |

## Core message mapping

- Failure points map 1:1 to DERO features: monitor-arm spec/VESA compatibility
  (spec judgment), lamp color temperature (mood), overall harmony (theme).
- S8's "operate on screen → reality follows" magic is the metaphor: verify in
  the simulator first and reality falls into place.
