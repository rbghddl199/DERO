## 0. 컨셉

**"차분한 라이트 캔버스 위, 온화한 웜옐로우 액센트와 유리 도구."**

- 기본 온도: **차분·감각적·감성적·고감도**. 실측 규격 검증 도구(D1)의 신뢰감이 우선.
- 시뮬레이터는 게임형 재미가 아니라 **디테일 강한 실사** 지향.
- 친근함·재미는 최하위 우선순위의 마이크로 디테일로만 (라운딩, 아이콘 미세 모션 수준).
- 스타일 4요소: Gradient Blur / Glassmorphism / Vibrant 3D / Organic Shape — 아래 규칙대로 영역 제한 적용.

## 1. 컬러

### 1.1 Base — 무채색 뼈대

- 배경: 웜 오프화이트 `#FAFAF9` 계열.
- 뉴트럴 그레이 스케일 9단계(50~900)로 텍스트·보더·서피스 구성. UI 뼈대는 무채색.

### 1.2 Primary — 웜옐로우 (액센트 전용)

- 기준색 `#E8A93A` 근방(허니·머스터드 톤, 채도를 낮춰 "온화함" 확보), 50~900 스케일 산출.
- 용도: 주요 버튼, 링크, 포커스 링, 선택 상태, 활성 탭.
- **넓은 면적 채우기 금지** — 배경 워시·대면적 섹션 컬러로 쓰지 않는다.

### 1.3 장식 그라디언트

- 웜옐로우 → 소프트 살구(피치) → 아이보리, 저채도 파스텔 한정.
- Gradient Blur(색 번짐)는 정적 화면 배경 장식에서만.

### 1.4 판정 시맨틱 (별도 축)

- 적합 = 그린 / 조건부 = 오렌지 / 불가 = 레드 (호환성 판정 3단계, D8).
- **프라이머리가 웜옐로우가 되면서 기존 "앰버" 조건부 색과 혼동 위험이 커졌다 — 조건부는 프라이머리보다 채도 높고 붉은 쪽으로 치우친 오렌지로 명확히 분리하고, 색만으로 구분하지 않도록 아이콘·라벨 병기를 필수로 한다.**

### 1.5 시뮬레이터 캔버스 — 색 중립 원칙

- 3D 환경(배경·바닥·기본 벽)은 뉴트럴 라이트 그레이.
- 캔버스 주변 웜옐로우 대면적 금지. **이유: 사용자가 제품 색 조화를 판단하는 공간(P1-PN3, 색 조화 니즈 54.1%) — UI 색이 강하면 제품 색 인지를 왜곡한다.**
- 웜옐로우는 HUD 액센트(버튼·선택 상태)로만 진입.

## 2. Glassmorphism

### 2.1 적용 범위 — 시뮬레이터 HUD 포함

- 3D 캔버스 위 모든 오버레이: 호환성 판정 카드, 실시간 견적, 측정 도구 HUD, 라이브러리 패널.
- 정적 화면의 카드·모달·설정 패널도 동일 토큰 사용.
- 의도: "공간 위에 떠 있는 도구" 감각 — 핵심 차별 경험.

### 2.2 토큰

| 속성 | 값 |
|---|---|
| 배경 | `rgba(255,255,255,0.6~0.75)` |
| blur | 12~16px |
| 보더 | 1px 밝은 보더(화이트 계열 반투명) |
| 그림자 | 소프트 섀도 (저채도·저불투명) |
| 텍스트 영역 | 배경 불투명도 하한 0.7 |

### 2.3 성능·가독성 규칙

- WebGL 위 backdrop-filter 동시 패널 수 권장 ≤ 3.
- blur 반경 상한 16px.
- 프레임 저하 시 폴백: 글래스 → 반투명 솔리드 (blur 제거, 불투명도 0.85).
- 금지: 글자 자체 반투명 처리, 글래스 위 글래스 중첩.

## 3. Vibrant 3D 아이콘

- **재질: 실사 미니어처 + 소프트 스튜디오 라이팅.** 실제 제품 비율 유지, 형태 과장 최소.
- 귀여움은 라운딩·색 온도 수준의 미세 디테일로만.
- 모티브: 데스크 오브젝트(책상·모니터·조명·케이블·상자 등) — 제작 중인 세트 계승.
- **해상도: 선명·고해상 렌더** (Toss 3D 아이콘 참조 포인트). 저해상 뭉개짐 금지.
- 용처: 기능 아이콘, 온보딩, 빈 화면, 카테고리 그래픽.
- 본문 UI 아이콘(내비게이션·액션)은 일반 라인 아이콘 별도 세트 — 3D 아이콘과 역할 분리.
- 모션: 아이콘별 부드러운 idle/hover 마이크로 애니메이션(플로팅·미세 회전). 과장 바운스 금지.

## 4. Organic Shape / Blob

- 용처: 랜딩·온보딩·빈 화면·커뮤니티 헤더의 **배경 장식만**. 저채도 웜옐로우/살구 계열 그라디언트 블롭 + 강한 blur.
- 금지: 시뮬레이터 작업 공간 내부, 판정·견적 등 정보 UI 뒤.

## 5. 타이포그래피

- **Pretendard** 단일 패밀리.
- 스케일: Display 32 / H1 24 / H2 20 / Body 15 / Caption 13.
- 수치(mm·원·kg)는 `tabular-nums` 고정폭 숫자.
- 카피 톤: 담백한 서술형. 느낌표·과장 카피 지양.

## 6. 모션

- 기조: 절제. 200~300ms, ease-out 기본.
- 페이지 전환·패널 슬라이드는 부드럽게. 시선을 뺏는 대형 모션 금지.
- 살아있는 곳(예외): 3D 아이콘 마이크로 모션, 호환성 판정 결과 등장 연출.

## 7. 영역별 적용 맵

| 영역 | 배경 | 글래스 | 3D 아이콘 | Blob |

| 랜딩·온보딩 | 오프화이트 + 그라디언트 블러 | 카드·CTA 패널 | 적극 | 적극 |
| 시뮬레이터 | 뉴트럴 그레이 3D 환경 | HUD 전부 | 빈 상태·툴 아이콘만 | 금지 |
