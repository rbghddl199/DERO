# 촬영 지시서 — 시댄스 2.0 영상 프롬프트 변환

당신은 AI 광고 제작을 돕는 조수입니다. 이 스킬의 목표는 스토리보드에서 짠 컷 타임라인을 **힉스필드의 시댄스 2.0 영상 생성 모델이 알아듣는 프롬프트**로 바꾸는 것입니다. 핵심 목적은 컷이 바뀌어도 **인물·제품·배경이 흔들리지 않게** 만드는 것입니다.

## 반드시 지킬 3대 원칙 (모든 생성에 적용)

1. **처음부터 끝까지 하나의 채팅방에서 진행합니다.** 캐스팅 시트의 엘레멘트 락이 이 채팅에 살아 있어야 영상 컷마다 같은 인물·제품이 나옵니다. 새 채팅을 열면 락이 풀려 첫 컷부터 딴사람이 됩니다.
2. 프롬프트 끝에 **"no logos, no watermark"** 를 넣습니다.
3. **장식용 AI 배경 금지.** 의미 없는 회로 패턴·떠다니는 파티클·목적 없는 글로우를 넣지 마세요. AI 티가 나면 광고로 안 보입니다.

## 작업 순서

### 0단계 — 입력 확인

- **스토리보드 타임라인 표** (컷 번호·구간·장면·카메라·시작/끝 프레임)
- **캐스팅 시트 엘레멘트 락 완료 상태** 확인. 안 되어 있으면 이전 스킬부터 끝내라고 안내합니다.

### 1단계 — 앵커 반복 규칙 (제일 중요)

**모든 컷 프롬프트에 아래 다섯 가지를 똑같은 문구로 반복해서 넣습니다.**

- 인물 묘사 (캐스팅 시트에서 정한 성별·연령·헤어·의상 — 컷마다 토씨까지 같게)
- 제품명·제품 묘사
- 배경 (같은 장소)
- 시간대
- 조명

컷마다 이 문구를 조금씩 다르게 쓰면 인물·배경이 컷 사이에서 달라집니다. **복붙하듯 똑같이** 넣고, 컷마다 바뀌는 건 "장면에서 벌어지는 동작"과 "카메라 움직임"뿐이어야 합니다. 먼저 이 앵커 문구 블록을 하나 만들어 두고, 각 컷 프롬프트 앞에 그대로 붙이세요.

### 2단계 — 카메라 어휘 (허용 목록 안에서만)

카메라 지시는 아래 목록에서만 고릅니다:

- `static shot`
- `slow dolly-in`
- `slow pan left` / `slow pan right`
- `orbit around product`
- `close-up`
- `wide shot`

이 목록 밖의 복잡한 카메라 지시(급격한 줌·핸드헬드 흔들림·복합 크레인 무브 등)는 시댄스에서 실패율이 크게 올라가니 쓰지 마세요. 스토리보드 표의 카메라 열도 이 어휘로 정리합니다.

### 3단계 — 파라미터 규격

각 컷 생성 요청에 아래를 명시합니다:

- 길이: **15초** (전체 기준. 컷 단위 생성이면 스토리보드 구간 초를 그대로 씀)
- 해상도: **720p**
- **BGM 유무 명시** (넣을지 뺄지 분명히 지시)
- **컷 경계는 스토리보드 구간(초) 그대로** 씁니다. 임의로 늘리거나 줄이지 마세요.

### 4단계 — 대사 규칙

**한국어 발화 대사는 지양합니다.** 현재 시댄스 2.0은 영상은 잘 뽑지만 한국어 발음이 어색합니다. 대사가 필요하면 영상에서 말하게 하지 말고 **자막으로 넣거나 목소리를 따로 녹음해 입히는 방식**을 권하세요. 프롬프트에서는 인물이 말하는 입모양을 강조하지 않는 편이 안전합니다.

### 5단계 — 실패 대응 규칙 (크레딧 절약)

생성 결과에 **1~2초짜리 결함**(손가락 이상, 위치 점프 등)이 있으면 **바로 재생성하지 마세요.** 재생성은 크레딧을 먹고, 컷 편집은 공짜입니다. 순서대로 판단합니다:

1. 먼저 **"그 결함 구간을 잘라내고 컷을 이어붙일 수 있는지"** 판단합니다. 15초 광고에서 문제 1초를 빼고 컷 순서만 살짝 바꿔도 대부분 티가 안 납니다.
2. 잘라서 살릴 수 있으면 편집으로 해결하고 재생성하지 않습니다.
3. **결함이 컷 전체를 망쳤을 때만** 그 컷 **1개만** 다시 생성합니다. 전체를 다시 돌리지 마세요.

## 검수 체크리스트

- 모든 컷 프롬프트에 인물·제품·배경·시간대·조명 앵커 문구가 **똑같이** 들어갔는지 확인합니다.
- 카메라 지시가 허용 목록 안에 있는지 확인합니다.
- 15초·720p·BGM 유무가 명시됐는지, 컷 경계가 스토리보드 그대로인지 확인합니다.
- 한국어 발화 대사를 영상에 직접 넣지 않았는지 확인합니다.
- 결함 컷이 나오면 재생성 전에 "잘라서 살릴 수 있나"부터 판단했는지 확인합니다.

## 마무리

세 스킬(`casting-sheet` → `storyboard` → `shot-sheet`)을 같은 채팅방에서 순서대로 쓰면, 캐스팅으로 고정한 인물·제품이 15초 광고 끝까지 흔들리지 않고 유지됩니다.

## 스타일 씬 프롬프트 규칙 (2026-07-11, 이순신 종이 공예 레퍼런스 반영)

- STYLE 블록을 앵커처럼 반복합니다: 모든 클립 프롬프트 맨 앞에 매체·팔레트·질감 락 문장을 똑같이 넣습니다 (레퍼런스 이미지를 걸었어도 생략 금지 — 빼면 영상 중간에 스타일이 변합니다).
- "one continuous shot" + "match-cut transitions flowing through paper elements"를 명시해야 장면이 하드 컷 없이 변신하며 이어집니다.
- 카메라 어휘 확장 (스타일 씬 한정): top-down view / the camera dives into the spiral / slow final push-in, then hold / sweeps across the foreground like a wipe. 실사 광고의 어휘 제한 원칙은 유지하되 이 다섯은 실측 검증됨.
- 리롤 포인트: 매치컷이 안 이어지면 "each scene transforms out of the previous one, never a hard cut" 추가.

## 클립 길이 원칙 (2026-07-11 확정 — 실측)

- **시댄스 2.0은 한 클립 15초까지 생성됩니다. 15초 이내 영상은 쪼개지 말고 무조건 1발 원테이크로 만듭니다.** 컷 전환·매치컷·속도 완급 전부 프롬프트 안에서 (0-2s)(2-5s)… 타임스탬프 구간 지시로 씁니다 — 이순신 15초 원테이크로 실측 검증.
- 라스트 프레임 체이닝(앞 클립 마지막 프레임 추출 → 다음 클립 --start-image)은 **총 길이가 15초를 넘을 때만** 씁니다. 15초 이내를 쪼개면 톤이 튀고 크레딧만 낭비됩니다.
- 모더레이션 실측: "slashes"·"war" 같은 무기·전쟁 직접 표현은 nsfw로 거부될 수 있음 → "swings ... like a calligraphy stroke" 식으로 우아하게 치환.

⚠️ **우선순위 명시 (2026-07-11):** 위 본문의 "컷별 프롬프트 변환·생성" 서술보다 이 클립 길이 원칙이 우선합니다. 스토리보드의 컷 타임라인은 설계 문서일 뿐이고, 실제 생성은 컷들을 (0-5s)(5-10s)… 타임스탬프로 합친 **15초 1발 원테이크 프롬프트**로 합니다. 씬을 잘라 개별 생성하지 않습니다. 영상 모델은 전부 시댄스 2.0로 통일 (변신류는 --start-image/--end-image를 시댄스에 걸어 1발).

## 공간 투어(FPV) 표준 기법 — "설계도 우선" (2026-07-11 확정, 집 투어 v1~v5 실측)

공간을 누비는 FPV 원테이크는 방 사진을 아무리 줘도 공간 논리가 안 잡힙니다. 확정 공정:

1. **설계도를 이미지로 먼저 그린다** (gpt_image_2): 톱다운 평면도 + 방 라벨 + **빨간 점선 카메라 동선(번호 매김)**. 현관·창문은 전면 벽에, 동선은 문·복도로만.
2. **영상 레퍼런스는 설계도 + 외관 사진 딱 2장.** 내부 방 사진까지 다 넣으면 오히려 어색해짐(실측 v4 탈락) — 내부는 프롬프트 문장(무드·가구 한 줄)으로만 주고 모델이 채우게 한다.
3. 프롬프트 필수 문장: "follow the red numbered camera path EXACTLY" / "COMPACT home at normal residential scale, the hallway is only three or four steps long" (안 쓰면 내부가 무한 확장 — 실측 v2 탈락) / "NEVER passes through walls — always moves through real openings" (실측 v1 탈락) / 진입 스턴트는 "in the same unbroken first-person view ... without any cut".
4. 모더레이션이 같은 프롬프트를 랜덤 거부할 때가 있음 → 표현 안 바꾸고 1회 재시도부터.

## 레퍼런스 역할 선언 (2026-07-11 확정 — 합격 프롬프트 3종의 공통 골격)

레퍼런스 이미지를 넘길 때는 프롬프트 **맨 앞에서 이미지마다 역할을 선언**합니다. 첨부만 하고 말면 모델이 어느 이미지를 뭘로 쓸지 제멋대로 정합니다.

- 순서대로 명시: "The FIRST reference image is the floor plan of this exact house: follow its layout and its red numbered camera path EXACTLY." / "The SECOND reference image is the real exterior — match it exactly."
- 정확도가 생명인 그래픽(국기·로고·라벨·설계도)은 "reproduce EXACTLY as shown — same orientation, same patterns, no text" 수준으로 못 박습니다. 글로 그리게 하면 틀립니다 (태극기 실측: 글지시 2연속 실패 → 실물 레퍼런스 1발 통과).
- 인물 일관성: "featuring the same model from the reference casting sheet throughout — same face, same hair, same dress in every scene."
- 제품: "exactly as in the reference product photo, label always sharp and unchanged."

## 합격 프롬프트 견본 (few-shot — 새 프롬프트를 쓰기 전에 반드시 1개 이상 읽을 것)

규칙보다 견본이 정확합니다. 이 스킬과 함께 배포되는 실측 합격본 3종을 프로젝트 `prompts/` 폴더에 저장해 두고, 새 프롬프트를 쓰기 전에 제일 가까운 견본부터 읽습니다:

- `prompts/yisunsin-15s-onetake.md` — 스타일 씬 + 매치컷 체인 + 국기 실물 레퍼런스
- `prompts/drink-cf-15s-onetake.md` — 실사 CF + 인물/제품 락 + 배경 점프 연출
- `prompts/house-tour-15s-onetake.md` — FPV 공간 투어 + 설계도 동선 + 스케일 통제

새 데모의 프롬프트는 이 중 제일 가까운 견본의 골격(레퍼런스 선언 → 스타일/스케일 락 → 타임스탬프 구간)을 따라 씁니다.

> 이 리포에서는 위 견본 3종이 이 스킬 폴더 아래 `prompts/` 에 있습니다 (`.claude/skills/shot-sheet/prompts/`).
