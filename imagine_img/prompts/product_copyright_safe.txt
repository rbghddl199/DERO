# 크롤링 제품 사진 -> 저작권에 걸리지 않는 자체 이미지 (2026-08-04, 임시 작업용)
#
# 쓰는 법:
#   python -m app.cli generate inputs/products/keyboard.png \
#       --prompt-file prompts/product_copyright_safe.txt \
#       --products "mechanical keyboard" --job-id kb-01
#
# 이 파일이 켜지면 prompt_builder(데스크 실사화 문장 조합)는 통째로 우회된다.
# 아래 글이 프롬프트의 유일한 출처다. 모델·strength·ControlNet 설정은 건드리지 않는다.
#
# --- 지금 쓰던 한국어 프롬프트를 어디에 옮겼는지 ---------------------------
#   "실제 놓여져 있는 모습 1컷으로"  -> 1번 블록 (single natural photo / in use / on a real surface)
#   "배경을 제품에 어울리게"          -> 2번 블록 (fitting environment, styled to the product)
#   "제품이 잘보이게"                -> 3번 블록 (hero subject, unobstructed, sharp focus)
#   저작권 회피                      -> 4번 블록 + [negative] 의 로고/문자 항목
#
# --- 2026-08-04 실측: 어떻게 돌려야 쓸 만한 것이 나오는가 ------------------
# 다나와 크롤링 이미지(products.id=528, NACODEX NK61 배너)로 세 번 돌려 확인한 것.
#
#   (1) 기본 설정 그대로 (CN 0.6 / strength 0.75)
#       -> **못 쓴다.** 배너 레이아웃과 브랜드 문자("NACODEX", "NK61 Mechanical keyboard")가
#          거의 그대로 남는다. RGB 조명과 재질만 바뀐다. 저작권 관점에서 원본 사진이다.
#   (2) CN 0.2 / strength 0.9 로 풀어 준 경우
#       -> 문자는 읽을 수 없게 부서지지만 **글자 블록이 있던 자리는 그대로 남고** 키보드가
#          뭉갠 흐린 형태가 된다. 상단 텍스트 영역이 화면의 절반을 먹고 있어서다.
#   (3) 제품 영역만 crop 한 뒤 CN 0.45 / strength 0.9   <-- 이 조합을 쓸 것
#       -> 책상 위에 놓인 실사 컷이 나온다. 배경(모니터·책상)이 새로 생기고, 제품이 크게
#          잘 보이고, 브랜드 문자는 붉은 얼룩 하나로만 남는다.
#
#   python -m app.cli generate <crop.png> --prompt-file prompts/product_copyright_safe.txt \
#       --products "mechanical keyboard" --strength 0.9 --job-id cr-01
#   (CONTROLNET_CONDITIONING_SCALE=0.45 를 환경변수로 준다. .env 를 고치지 않아도 된다.)
#
# 즉 **판촉 배너를 그대로 넣으면 안 된다.** 이 파이프라인은 img2img 라서 입력 화면의
# 구성을 물려받는다. 문자·로고·여러 컷이 붙은 이미지는 제품 영역을 먼저 잘라내야 한다.
# 색상 변형 4컷을 넣으면 결과도 흰 배경 4컷이 된다 — 아래 "1컷" 지시가 ControlNet 에 진다.
#
# 그리고 **카테고리마다 canny 강도가 다르다.** 모니터는 화면 사진과 로고가 윤곽에 들어와
# 있어서 0.15 까지 낮춰야 지워진다 (app/product_batch.py CATEGORY_CONTROLNET_SCALE).
# `batch-products` 는 그 표를 자동으로 적용한다.
#
# --- 흰 배경은 프롬프트로 못 없앤다 (2026-08-04 실측) ----------------------
# 쇼핑몰 사진처럼 **배경이 흰색인 입력**은 결과도 흰 배경이 된다. 아래 §2 의 "제품에 어울리는
# 환경" 지시가 무시되는 것이다. 라이프스타일 사진이 입력이면 잘 나오므로, 배경은 프롬프트가
# 만드는 것이 아니라 **입력에 있는 것이 남는 것**이다.
#
# 흰 배경을 방으로 바꾸려고 시험한 것과 결과 — 전부 실패했다. 다시 시도하지 말 것:
#
#   strength 0.9 -> 1.0 (입력을 완전히 노이즈로 덮음)   흰 배경 그대로, 제품만 망가짐
#   CN 0.45 -> 0.25 -> 0.10                          흰 배경 그대로, 0.10 은 시계가 카메라로
#   control_guidance_end 0.5 (후반 스텝에서 조건 해제)  흰 배경 그대로
#   프롬프트를 장면 먼저 쓰도록 재배열                  흰 배경 그대로
#   negative 의 흰 배경 금지어 (이미 아래에 있다)       효과 없음
#
# 원인은 canny 조건 이미지다. 제품 외곽선 바깥이 비어 있어서 그 영역이 "아무것도 없음" 으로
# 남는다.
#
# **그래서 배경은 2단계에서 만든다** — 1단계 결과에서 배경 영역을 마스크로 골라 inpaint 로
# 다시 그린다 (app/generation/background.py, scene.py). 배경 프롬프트는 이 파일 아래
# [background] 섹션이다. 위 목록은 "프롬프트로 해보려다 실패한 것" 의 기록이니, 배경이
# 마음에 안 들면 strength·CN 을 만지는 대신 [background] 섹션을 고칠 것.
#
# --- 프롬프트가 못 하는 일 -------------------------------------------------
# 1) 프롬프트는 저작권 판단을 대신하지 못한다. 여기 적은 문장은 "로고·문자·고유 장식을
#    빼고 새로 찍은 사진처럼 만들라"는 지시일 뿐이다. 원본과 얼마나 멀어졌는지는 위
#    strength·ControlNet 조합이 정하고, 마지막 판단은 사람이 원본과 나란히 놓고 해야 한다.
# 2) CLIP 은 부정문을 못 읽는다("no logo" 의 no 를 무시한다). 그래서 빼야 할 것은
#    positive 가 아니라 [negative] 에 적었다. NEGATIVE_PROMPT_PROFILE 은 이 파일을 쓰는
#    동안 무시되고, 아래 [negative] 블록이 그대로 실린다.
# 3) 로고 자리에 남는 얼룩은 negative 로 완전히 지워지지 않는다. 원본에 로고가 크게
#    박혀 있으면 그 부분을 crop 에서 빼거나, 나온 이미지에서 사람이 확인해야 한다.

# 블록 사이 빈 줄과 주석은 사라지고 **모든 줄이 공백 하나로 이어붙는다.** 그래서 각 블록의
# 마지막 줄은 마침표(negative 는 쉼표)로 끝낸다 — 없으면 "realistic exposure an environment"
# 처럼 두 문장이 한 구절로 붙어 CLIP 이 엉뚱한 개념으로 읽는다.

# 1. 실제 놓여져 있는 모습 1컷 — 카탈로그 컷이 아니라 쓰이는 자리에 놓인 사진
a single photograph of one {products} sitting in the place where it is actually used,
resting on a real surface with its own weight, casually placed rather than arranged,
one natural camera angle slightly above the object, three-quarter view,
shot on 50mm lens at f/2.8, natural vignette, fine film grain, realistic exposure.

# 2. 배경을 제품에 어울리게 — 제품 성격에 맞는 공간을 만들어 넣는다
an environment that suits this product, styled to match its material and colour,
believable room behind it with soft depth of field, out-of-focus background,
a few plain everyday objects nearby for scale, natural window light from one side,
soft contact shadow directly under the object, ambient occlusion where it meets the surface.

# 3. 제품이 잘 보이게 — 주인공이 흐려지거나 가려지지 않게
the product is the clear subject, large in frame, fully visible and unobstructed,
sharp focus on the product body, clean silhouette separated from the background,
even light across the product, no harsh glare on its surface, its shape easy to read.

# 4. 저작권 — 브랜드 흔적이 없는, 이 제품 종류의 일반적인 물건
a generic unbranded product of this kind, plain unmarked surfaces,
original everyday industrial design, simple neutral form,
matte and brushed material finish with real dust and micro-scratches,
newly photographed, not a copy of any existing catalogue image.
